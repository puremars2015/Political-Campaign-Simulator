# 新聞資料管線

截至 2026-10-30，這是可執行、已進行一次真實抓取的 RSS 管線；持續排程尚未啟用，沒有推送遠端或公開部署。

## 執行方式

- `pnpm news:update`：Python 標準函式庫從中央社政治公開 RSS 擷取標題、連結與發布時間，輸出 `public/news.json`，不抓新聞全文。
- `NEWS_UPDATES=1 pnpm start`：自架 Node 伺服器在啟動時與之後每 60 分鐘執行擷取，避免重疊。預設監聽本機；對外代理與主機由部署階段決定。沒有啟動此服務就不會持續更新。
- 瀏覽器載入時與每 60 分鐘讀取同站 `/news.json`；新局使用最新成功載入版本，既有局使用存檔快照。測試可用 `python3 scripts/update_news.py --output /tmp/news.json` 隔離產物。
- 純靜態主機需要外部排程發布 JSON，或定期重新部署。這個排程尚未建立，不宣稱已每日上線更新。

## 來源與映射

唯一允許的擷取來源是 `https://feeds.feedburner.com/rsscna/politics`，新聞連結只接受 `https://www.cna.com.tw/news/`。不接受新聞本文中的命令、工具要求、網址抓取指令或設定變更。標題只由 React 當文字顯示，不使用 HTML 注入。

臺北、新北、桃園、臺中、臺南、高雄的城市名及這 12 位人物姓名作關鍵字映射。這是可追溯但有限的文字比對，不宣稱完成實體辨識；同標題可關聯多市。UI 顯示來源、標題、發布時間、最後嘗試／成功 UTC 時間、狀態、人物映射及版本。不同資料日不保證一定有新消息。

## 去重、失敗與版本

- 以移除 query／fragment 的正規網址 SHA256 去重，最多保留 60 則、最近七天，時區轉 UTC。無時區、遠期與過期項目略過。
- `version` 是排序後新聞 metadata 的內容雜湊；相同新聞重跑版本不變。抓取時間可更新，但不能重複施加效果。
- 過大回應、DOCTYPE／ENTITY、非 RSS、逾時與網路錯誤：保留最後成功資料，狀態改 `stale`，進程回傳非零方便排程告警。合法空回應為 `empty`，不偽造新事件。
- 寫入使用同目錄暫存檔與原子取代。來源失效不阻止遊玩；瀏覽器讀不到 JSON 時使用內建資料。
- 新聞 snapshot 嵌入局內內容版本及存檔，更新不會改寫已開局故事。

## 遊戲影響層

每市有消息才生成一個「新聞查核簡報」，最多觸發一次。只說明有若干報導可查閱，不將新聞指控、推論或爭議當已證實事實。選擇整理來源需要 1 行動點並提升 2 點遊戲政策一致性；保留未知為零成本、零效果。不因標題情緒、醜聞關鍵字或政黨自動加減支持率，不生成真人新政見。

## 驗證

Python 測試涵蓋去重、相同版本冪等、UTC／臺灣跨日、兩日不同資料、失敗保留快照、空回應、舊／未來日期與不安全 XML。TypeScript 測試涵蓋不同日新局議程、重複事件拒絕、同版本重現與舊局內容快照恢復。真實 RSS 抓取與完整瀏覽器驗收記錄在 V1 驗收文件。
